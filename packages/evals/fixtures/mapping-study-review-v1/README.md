# Original independent-review bindings

`baseline.json` records the input, gold, family and artifact hashes at the
immutable source commit reviewed in
[the independent review record](../../../../docs/MAPPING_STUDY_V1_GOLD_REVIEW.md).
It also retains the original canonical tuples and whole-input expectations so
changed gold cannot inherit the review merely by retaining its input hash.
`baseline.sha256` binds its original UTF-8 bytes. The baseline is separate from
the corrected, still-unsealed drafts and is not regenerated by their generator.

Original bytes can be recovered without a network request:

```bash
git show 35a023581d0d5e90b77b651b9f4c09fed2cce790:packages/evals/fixtures/mapping-study-v1/SELECT.inputs.json
```

Use the full `sourceCommit` in `baseline.json` if the abbreviation is unavailable
in a shallow checkout; that commit must first be present locally. Checksums
establish integrity and bindings, not reviewer authenticity or absence of
training exposure. The original reviewer was an AI assistant; acceptance of that
independence procedure remains a pre-registration audit question. This baseline
contains synthetic fixtures and no provider or human-performance observations.
