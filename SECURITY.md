# Security policy

Do not open a public issue for a suspected vulnerability or accidental data
exposure. Until a dedicated security contact is published, use GitHub's private
vulnerability reporting for this repository.

Never include API keys, provider traces containing sensitive inputs, real order
or trade data, customer identifiers, or production schemas in a report.

WeaveTrail is a research-oriented reference harness, not a certified market
surveillance, compliance, legal, or investment system. See
[Limitations](docs/LIMITATIONS.md) for the complete boundary.
