# 종목과 지수 이름 연결

영문 문서가 기준입니다. [English](INSTRUMENT_RESOLUTION.md)

`@weavetrail/instrument-resolver`는 사건 날짜를 기준으로 전달받은 이름이나 코드를
조회합니다. 검증·반입된 목록과 일별 시세 연결 정보를 인자로 받으며, 저장소를
열거나 URL을 가져오거나 모델을 호출하지 않습니다. 애플리케이션 조합 코드가
불변 입력을 확인해 전달합니다.

## 계약과 매칭

새 계약 버전은 `1.0`이며 `@weavetrail/contracts/instrument-resolution`과 계약
패키지의 기본 진입점에서 제공합니다. 기존 이벤트·항목 연결·승인·증거 계약의
마이그레이션은 필요하지 않습니다. 새 API를 사용하는 호출자는 다음을 전달합니다.

- `query`(1–256자)와 `eventDate`(`YYYY-MM-DD`). 호출자가 사건의 달력 날짜를
  정합니다. 연결기는 시간대를 추정하지 않습니다.
- `InstrumentListing`: 목록 식별자, 출처 기록, 중복 없는 종목 식별자. 각 이름과
  코드에는 종류, 원문 값, 양 끝을 포함하는 `validFrom`/`validThrough`, 출처 ID,
  1부터 시작하는 행 번호와 열 이름이 있습니다.
- 데이터셋 ID, 종목 ID, 출처 기록, 실제 관측 날짜를 갖춘 일별 시세 연결 정보.
  중간에 빈 날짜가 있는 기간만으로 시세 존재 여부를 판단하지 않습니다.

식별자 종류는 `SHORT_CODE`, `ISIN`, `KOREAN_NAME`, `ENGLISH_NAME`,
`ABBREVIATION`, `FORMER_NAME`입니다. 영문명과 약칭은 출처와 함께 명시해야 하며,
번역이나 약칭 생성은 하지 않습니다. 이전 이름은 기록된 유효기간에만 매칭됩니다.
앞자리 0, 문장부호, 주식 종류를 구분하는 접미사를 보존합니다. 유니코드 NFC 정규화,
바깥 공백 제거, ASCII 영문 대소문자 통일만 수행하고, 내부 공백을 유지합니다.
부분 문자열이나 편집 거리, 유사도를 이용한 매칭은 없습니다. 한 종목의 여러
식별자가 일치하면 한 후보에 여러 근거를 붙입니다. 다른 종목의 동일한 이름보다
코드를 우선하지 않습니다.

| 결과                                          | 동작                                                                                     |
| --------------------------------------------- | ---------------------------------------------------------------------------------------- |
| `RESOLVED`                                    | 사건 날짜에 한 종목만 일치합니다. 원문 식별자, 유효기간과 출처 좌표를 근거로 반환합니다. |
| `REVIEW_REQUIRED` / `AMBIGUOUS_NAME`          | 여러 종목이 일치합니다. 모든 후보와 근거를 반환하며 시세를 연결하지 않습니다.            |
| `UNRESOLVED` / `NO_EXACT_MATCH`               | 목록에 같은 식별자가 없어 연결하지 않습니다.                                             |
| `UNRESOLVED` / `NAME_NOT_VALID_ON_EVENT_DATE` | 같은 식별자는 있지만 사건 날짜가 기록된 유효기간에 없습니다.                             |

종목이 확정되어도 시세 상태는 별도로 표시합니다. 사건 날짜가 반입된 연결 정보에
있으면 `LINKED`, 없으면 `UNAVAILABLE`과 `NO_ADMITTED_QUOTES_ON_EVENT_DATE`를
반환합니다. 시세의 유무로 모호한 이름을 확정하지 않습니다. 잘못된 계약 형태,
검토되지 않은 재사용 허용 플래그, 취득 후에 검토한 허가, 존재하지 않는 근거 출처,
중복 종목·출처 ID, 중복 데이터셋/종목 연결과 같은 출처 ID의 상충하는 메타데이터는
조회 전에 예외로 거부합니다. 날짜 목록의 중복도 거부하므로 호출자가 날짜를
명시적으로 합쳐야 합니다. 이러한 실패는 연결된 종목이나 규칙 결과를 만들지 않습니다.

## 스냅숏 결속

모호하거나 찾지 못한 결과도 목록 ID, 정준 SHA-256 지문과 출처 기록을 남깁니다.
출처 기록은 발행기관, 원본 URL, 취득 시각, 검토한 재사용 조건, 저작자 표시,
수집기/투영 버전과 출처 기록 URL을 보존합니다. 허용 플래그는 운영자가 검토한
반입 근거이며 Zod가 법적 허가를 판단한 결과가 아닙니다.

커밋된 자료 참조에는 아티팩트 ID와 SHA-256, 원본 응답 바이트의 경로와 해시가
있습니다. 서비스 자료 참조에는 불변 스냅숏 ID와 원본 바이트 SHA-256이 있습니다.
서비스 입력은 조합 코드가 저장된 스냅숏을 읽어 해시를 다시 확인한 뒤 전달해야
합니다. 연결기는 원본 URL을 다시 가져오지 않습니다.

목록 지문의 해시 입력은 스키마 버전, 목록 ID, 출처 ID/참조와 유효기간·근거를
갖춘 식별자 목록입니다. 출처는 출처 ID로, 종목은 종목 ID로, 식별자는 정준 JSON으로
코드 단위 정렬합니다. 취득·허가 검토 시각과 표시용 출처 메타데이터는 제외합니다.
이름의 실제 유효 날짜와 불변 참조는 포함합니다. 이 지문은 조회 입력의 식별자이며,
재현 결과 해시나 발행기관 진위 또는 사람의 승인을 증명하지 않습니다. 연결기 버전
`exact-dated-identifiers-v1`은 별도로 기록합니다.

## 합성 입력 범위

실제 시세에서 만든 종목 목록과 앱 연결은 철회되었습니다. 알고리즘은 호출자가 제공한 합성 목록으로 검증합니다.

## 재현과 한계

```bash
pnpm exec vitest run packages/instrument-resolver/src/resolver.test.ts packages/instrument-resolver/src/dependency-boundary.test.ts
```

테스트는 한국어·영문명, 약칭, 단축코드, ISIN, 합성 회사의 이름 변경 전후, 코드
재사용, 이름 충돌, 일치하지 않는 이름, 시세 부재, 스냅숏 참조, 원본 바이트 해시와
입력 순서 불변성을 검증합니다. 의존성 테스트는 런타임 공개 진입점과 타입 import를
따라 계약·커널까지 추적하며 모든 종류의 워크스페이스 의존 선언을 고정합니다.
연결기는 저장소·공급자·규칙 코드를 불러오지 않습니다.

찾지 못한 결과는 전달한 목록의 범위만 설명합니다. 전체 시장에서 종목이 존재하는지
판단하지 않습니다. 이름 연결은 입력 준비이며, 패턴 지지·법적 결론·인과관계·투자
추천을 성립시키지 않습니다.
[ADR 0051](adr/0051-resolve-exact-dated-identifiers-over-admitted-listings.md)(영문)을
참고하세요.
