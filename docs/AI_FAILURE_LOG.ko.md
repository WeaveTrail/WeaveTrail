# AI 실패 기록

_[English](AI_FAILURE_LOG.md) · 영문 문서가 기준입니다._

관찰된 모델·검증기 실패, 그 실패가 깨뜨린 가정, 그리고 이에 대응한 변경을
기록합니다. 각 항목은 일회성 수정 메모가 아니라 공개 엔지니어링 이력입니다.
항목은 추가만 합니다. 이미 수정된 실패를 나중에 다시 바꾸면 이전 항목을
참조하는 새 항목을 씁니다.

실제로 관찰한 사례만 기록합니다. 커밋된
[`mapping-run/1` 기록](EVALUATION.ko.md)이 이미 담고
있는 범위를 넘는 원문 모델 출력은 인용하지 않습니다. 오프라인 프로브의 경우
반례는 커밋된 직접 작성 픽스처와 관찰된 검증기 결과입니다.

[`CONTRIBUTING.md`](../CONTRIBUTING.md#change-requirements)(영문)는 모델·검증기
실패를 고치는 변경이 이 기록의 항목과, 수정 없이는 실패하는 회귀 테스트를 함께
포함하도록 요구합니다. [기록 점검](../packages/evals/src/ai-failure-log.test.ts)은
`pnpm test`에서 실행되며, 항목이 불완전하거나 Git이 추적하지 않거나 테스트 스위트가
수집하지 않는 테스트 파일을 지목하면 실패합니다. 또한
[프롬프트 버전](#프롬프트-버전)에서 정한 범위의 모든 프롬프트 버전을 TypeScript
타입 검사기로 해석해, 그 표에 없거나 문자열 리터럴 타입이 아니면 실패합니다.

## 항목 필드

`F-001`부터 연속 번호를 붙인 각 `F-nnn` 항목은 다음을 밝힙니다.

| 필드        | 내용                                                                               |
| ----------- | ---------------------------------------------------------------------------------- |
| 역할        | 출력이 실패했거나 잘못 판정된 제한된 역할                                          |
| 모델과 버전 | 요청·보고된 모델, 또는 `검증기`와 그 버전이나 커밋                                 |
| 실행 기록   | `mapping-run/1` 기록 참조, 또는 기록이 없는 이유                                   |
| 가정        | 프롬프트, 계약 또는 검증기가 전제한 것                                             |
| 반례        | 가정을 깨뜨린 형식(dialect)·프로필 ID와 관찰된 출력                                |
| 수정        | 계약, 검증기, 프롬프트 버전 또는 라우팅 변경과 해당 PR                             |
| 회귀 테스트 | 수정 없이는 실패하는 커밋된 테스트 파일                                            |
| 상태        | `FIXED`, 또는 `ACCEPTED_RESIDUAL`과 잔여 위험을 받아들이는 이유·현재 처리하는 위치 |

## 프롬프트 버전

Git이 추적하는 테스트 외 소스의 모든 프롬프트 버전을 나열합니다. `promptVersion`
속성에 쓰이는 값(객체 리터럴, 축약형, 대입, 기본값)과 `*PROMPT_VERSION` 선언이 대상입니다.
테스트 픽스처에만 나오는 식별자는 모델에 전달되지 않으므로 나열하지 않습니다.
보류(held-out) 세트가 만든 출력이 프롬프트, 계약, 검증기 또는 라우팅 변경에
영향을 주면 그 세트는 소진된 것이며, 더 이상 보류 세트로 보고할 수 없습니다.

| 프롬프트 버전                        | 역할과 출처                                                                                                                                               | 도입            | 변경 내용과 이유                                                                                  | 보류 세트 소진                                                                                                                |
| ------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------- | ------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- |

[스키마 형식 HELD_OUT 봉인](../packages/evals/fixtures/schema-dialects-v1/HELD_OUT.sha256)(영문)으로 실행한 모델 없음 |

### F-001: 설정된 매핑 검증이 변환 불가능한 출력을 통과시킴

| 필드        | 값                                                                                                                                                                                                                                                                                                                                                                        |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 역할        | 설정된 어댑터의 필드 매핑 출력 검증                                                                                                                                                                                                                                                                                                                                       |
| 모델과 버전 | 검증기: `mapping-validator/1` 이전 설정된 어댑터의 `validateConfiguredProposal` 검증, `9b15a96` 시점                                                                                                                                                                                                                                                                      |
| 실행 기록   | 없음. 로컬 전송 함수를 주입한 `hostile-mapping-fixtures/1` 오프라인 프로브이며 모델을 호출하지 않았고 `mapping-run/1` 기록도 없음                                                                                                                                                                                                                                         |
| 가정        | 엄격한 제안 계약, 제공 열 검사, 필수 대상 검사를 통과한 제안은 선언된 변환으로 변환할 수 있다                                                                                                                                                                                                                                                                             |
| 반례        | 입력 `hostile-synthetic/1`. 프로브 `target-transform-mismatch`는 `id`를 `DECIMAL_STRING`으로 `sourceEventId`에 연결하고, 프로브 `transform-fails-on-rows`는 ISO-8601 샘플의 `time`을 `EPOCH_MS_TO_ISO`로 `eventTime`에 연결함. `9b15a96`의 어댑터는 두 경우 모두 `REVIEW_REQUIRED` 대신 승인 가능한 제안을 반환함. 나머지 24개 프로브는 거부되었고 유효한 대조군은 통과함 |
| 수정        | 검증기: `validateMappingOutput`(버전 `mapping-validator/1`)이 대상·변환의 구조적 호환성(`TARGET_TRANSFORM_MISMATCH`)을 확인하고 모든 제공 샘플 행에 실제 ingest 변환을 시험 적용(`TRANSFORM_FAILED`)함. 설정된 어댑터와 봉인된 제안 재검증이 이를 사용함. #296, [ADR 0059](adr/0059-share-the-model-mapping-validator-with-hostile-probes.md)(영문)                       |
| 회귀 테스트 | `packages/evals/src/adversarial-mapping.test.ts`                                                                                                                                                                                                                                                                                                                          |
| 상태        | `FIXED`                                                                                                                                                                                                                                                                                                                                                                   |

2026-10-06에 관찰했으며 커밋된
[이력 재현 테스트](../packages/evals/src/history/f-001-pre-269-gate.test.ts)로
재현합니다. 이 테스트는 [픽스처 파일](../packages/evals/src/adversarial-mapping-fixtures.ts)의
커밋된 프로브와 유효한 대조군을 `9b15a96` 시점 검증의
[이력 사본](../packages/evals/src/history/configured-provider-9b15a96.ts)에 있는
`ConfiguredSchemaMappingProvider`에 회귀 테스트와 같은 오프라인 설정·로컬 전송
함수로 적용합니다. 사본은
`git show 9b15a96:packages/ai-harness/src/configured-provider.ts`와 비교해 네 줄
머리말과 `./provider` import 지정자만 다르며, 재현 테스트가 두 차이를 되돌린 뒤
원본의 SHA-256을 확인합니다. `pnpm test`가 CI에서 실행하며, 별도로 실행하려면:

```bash
pnpm exec vitest run packages/evals/src/history/f-001-pre-269-gate.test.ts
```

건수는 고정된 의존성과 Node 22.18.0, pnpm 10.33.2, Vitest 5.0.2, Linux x86_64(WSL2
커널 6.18.33.2) 환경에서 관찰·재현했습니다. 프로젝트는 Node 22.13 이상을
지원합니다. 이 건수는 `hostile-mapping-fixtures/1`의 직접 작성한 합성 프로브
26개에만 해당하며, 모델이나 임의 출력에 대한 검사 범위를 측정한 것이 아니라
검증기 회귀 관찰입니다. 이제 두
프로브는 회귀 테스트에서 위 사유 코드로 거부됩니다.
