# Published acquisition withdrawal

The committed quotation sources and their application composition have been withdrawn. No real quotation data is offered in the current tree. See [ADR 0056](adr/0056-withdraw-the-committed-real-data-tier.md).

The manual acquisition scripts, publisher adapters, acquisition verification
and source registrations have been removed. No collection route or replacement
private host is added. Generic contracts and the existing service-store library
remain tested with synthetic inputs; the web app does not use that store.

Earlier acquisition decisions are historical records under the supersession
notice in ADR 0056. They describe no currently admitted real artifact.
